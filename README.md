# OrçaFácil IA

Aplicativo SaaS mobile-first para criação de orçamentos. Projeto independente da série **IA na Prática**.

## Executar

```bash
npm install
npm run dev
```

## Verificar

```bash
npm run build
npm test
```

## Etapa 1

- React + TypeScript + Vite + Tailwind CSS
- Dashboard com indicadores zerados (sem dados fictícios)
- Navegação responsiva e páginas preparadas
- Botão Novo orçamento com aviso explícito da Etapa 2
- Testes iniciais de formatação monetária

**Atenção:** cadastro, cálculos de orçamento, persistência, PDF e internacionalização ainda não estão implementados. Não insira dados reais nesta versão.
